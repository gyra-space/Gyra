# 场景空间(工作空间)

> 场景空间是 Gyra 的顶层协作容器。一个空间对应一个业务场景(如"运营分析""客服巡检"),
> 把相关的人、Agent、任务、数据资产组织在一起。

## 一、场景空间里有什么

- **对话区**:与场景专属 Agent 多轮对话,支持上传文件、看图、可视化结果。
- **任务列表**:空间里正在进行和已完成的任务,可点开看执行过程与产物。
- **成员**:邀请同事加入空间,按角色分配权限(查看/编辑/管理)。
- **资产**:空间沉淀的文档、数据、产物(文件、图表、报告)。
- **触发器 / 剧本**:配置定时或事件触发,让 Agent 自动跑标准流程。

## 二、常见操作

### 创建一个场景空间
1. 左侧主导航进入"场景空间"。
2. 点击"新建空间",填写名称与说明。
3. 选择或创建一个场景 Agent 作为空间的"队长"。
4. 邀请成员、绑定数据源和知识库。

### 在空间里提问
在对话输入框直接描述需求,例如"汇总本月销售数据并出图"。
Agent 会自动调用绑定的数据源、知识库和工具完成。

### 配置一个定时任务(触发器)
1. 进入空间 → "任务" → "触发器"。
2. 新建触发器,选择"定时"类型,填写 cron 表达式(如 `0 9 * * *` 表示每天 9 点)。
3. 填写要 Agent 执行的任务描述,保存。
4. 到点后 Agent 自动执行,结果可在"任务"列表查看。

## 三、经验沉淀(飞轮)

空间会把成功的任务流程沉淀为"剧本(Playbook)",下次遇到类似任务时
Agent 会复用或改进剧本,越用越顺手。你可以在空间内查看和编辑这些剧本。

## 四、常见问题

- **空间里看不到成员管理?** 需要空间的管理角色。
- **Agent 查不到我的数据?** 检查空间是否绑定了对应数据源或知识库。
