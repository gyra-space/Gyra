# 平台 FAQ(常见问题汇总)

## 账号与登录
- **忘记密码?** 联系系统管理员重置;管理员可用系统助手批量处理。
- **能用企业账号登录吗?** 支持 OAuth2 第三方登录(需管理员在系统配置中开启)。

## 功能可见性
- **为什么看不到"系统管理"?** 该入口仅对管理员角色可见,普通用户无权限。
- **为什么别人能用的功能我没有?** 菜单按权限显示,请联系管理员为你的角色开通对应资源权限。

## 对话与 Agent
- **Agent 回答的功能手册里没有?** 手册会持续完善;请反馈给管理员补充文档,助手能力随文档更新。
- **Agent 查不到我的数据?** 确认对应数据源/知识库已绑定到当前应用或空间,且已连接成功。
- **上传的文档多久能被 Agent 用到?** 文档解析与知识结构化是异步的,通常几秒到几分钟;
  可在知识空间的任务列表查看进度。

## 数据与安全
- **Agent 会不会改坏我的数据?** 默认只读;写操作需显式授权并逐次确认,全程有审计日志。
- **我的对话和文档别人能看到吗?** 知识空间有私有/共享之分;对话内容遵循空间与资源的权限设置。

## 自动化
- **定时任务没执行?** 检查 cron 表达式、时区,以及任务是否被暂停;执行历史在"任务引擎"查看。
- **怎么把结果发到群里?** 先配置消息渠道(飞书/钉钉),再在任务里绑定该渠道。

## 获取帮助
- **哪里看某个模块的详细用法?** 直接问系统助手,例如"知识库怎么用""怎么接入数据源"。
- **助手也答不上来?** 说明手册未覆盖,请联系管理员补充文档或查阅官方文档。
