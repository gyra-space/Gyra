# 应用构建(专家 / Agent)

> 应用(也称"专家"或"Agent 应用")是 Gyra 的核心交付物:
> 一个可被对话调用的智能体。你可以基于模板快速创建,也可以深度编排。

## 一、应用的组成

一个应用 = **提示词(角色设定)** + **工具(能做什么)** + **知识(知道什么)** + **技能(怎么做)**。

- **提示词**:定义 Agent 的角色、语气、行为边界。
- **工具**:Agent 可调用的动作,如查数据库、搜知识库、生成图片、调外部 API(MCP)。
- **知识库**:绑定的知识空间,Agent 回答时会检索引用。
- **技能(Skill)**:标准操作流程,Agent 遇到对应任务时按流程执行。

## 二、创建一个应用

1. 左侧导航进入"能力 → Agent"(或"应用")。
2. 点击"新建应用",选择模式:
   - **单 Agent**:一个智能体独立完成,适合大多数场景。
   - **多 Agent 编排**:多个 Agent 分工协作,适合复杂流程。
3. 填写名称、描述,编写角色提示词。
4. 在"资源绑定"中挂载工具、知识库、技能。
5. 点击"发布",应用即可在对话中使用。

## 三、绑定能力

### 绑定知识库
在应用编辑页 → 资源 → 添加"知识库",选择已建好的知识空间。
绑定后 Agent 会自动获得 `search_knowledge` / `read_knowledge_document` 检索能力。

### 绑定技能
在资源中添加"技能",选择技能市场里已发布的技能包。
Agent 会在上下文中看到可用技能列表,遇到匹配任务自动加载执行。

### 接入外部工具(MCP)
在"能力 → MCP"配置外部工具服务后,回到应用绑定该 MCP 服务,
Agent 即可调用这些外部工具。

## 四、常见问题

- **应用发布后改提示词不生效?** 内置应用的提示词以代码仓库为准,重启会自动同步;
  自建应用保存即生效。
- **Agent 不调用我绑的工具?** 检查工具是否真的绑定成功,以及提示词里是否引导它使用。
