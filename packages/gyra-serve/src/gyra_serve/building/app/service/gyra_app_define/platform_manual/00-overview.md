# Gyra 平台总览

> 本手册面向平台所有用户,帮助你快速理解 Gyra 是什么、能做什么、从哪里开始。

## 一、Gyra 是什么

Gyra 是一个 AI Agent 应用平台。你可以把它理解为一个"智能同事"的运行环境:
你创建或选用一个 Agent(智能体应用),它就能在对话中帮你查数据、写报告、
操作工具、定时跑任务,并把经验沉淀下来越用越聪明。

## 二、核心概念速览

| 概念 | 一句话说明 | 在哪里用 |
|---|---|---|
| 场景空间 | 顶层协作容器,把对话、任务、成员、资产组织在一起 | 左侧主导航"场景空间" |
| 应用 / 专家(Agent) | 一个可对话的智能体,由提示词+工具+知识+技能组成 | "能力 → Agent" |
| 知识库 | 上传文档形成可检索的知识空间,供 Agent 引用 | "资产 → 知识库" |
| 技能(Skill) | 可复用的标准操作流程包,Agent 按需加载执行 | "能力 → Skill" |
| 数据源 | 接入数据库,让 Agent 能查询真实业务数据 | "资产 → 数据库" |
| 定时任务(Cron) | 让 Agent 在指定时间自动执行并投递结果 | "能力 → Cron" |
| 权限(RBAC) | 基于角色的访问控制,管理谁能看/改什么 | "设置 → 权限" |

## 三、新手上路三步

1. **先聊一聊**:打开任意场景空间,向场景 Agent 提问,例如"帮我看看今天有哪些任务"。
2. **再问助手**:遇到不会用的功能,直接问"系统助手"(本助手),例如"怎么接入数据源"。
3. **动手做一个**:在"能力 → Agent"里基于模板创建一个自己的应用,绑定一个知识库,就有了专属的问答助手。

## 四、按角色找入口

- **普通业务用户**:日常在"场景空间"对话、看任务;在"知识库"查阅文档。
- **应用搭建者**:在"能力 → Agent / Skill / MCP"组装和发布应用。
- **数据/语料管理员**:在"资产 → 数据库 / 知识库 / ECP"维护数据与语义资产。
- **系统管理员**:在"设置 → 权限 / 配置 / 监控"做运维;也可让系统助手代为执行用户/角色管理。

## 五、常见问题

- **找不到某个菜单?** 菜单按权限显示,看不到通常是没有对应资源的读权限,联系管理员开通。
- **助手答不上来?** 说明本手册还没覆盖该主题,可反馈给管理员补充文档,助手能力会随文档更新而增强。
