# 知识库(知识空间)

> 知识库用于存放文档,并自动把文档组织成可检索的知识结构。
> 绑定到应用后,Agent 回答问题时就会引用这些文档。

## 一、知识库是怎么工作的

你上传一份文档,系统会:
1. 保存**原文**(不可变,作为事实依据);
2. 由 AI 自动生成**结构化的 wiki 文档**(带目录、概念关联);
3. 建立**实体与关系**,让相关文档互相链接。

Agent 检索时优先查这些结构化内容,再给答案,比传统"切片搜索"更准确、更有上下文。

## 二、创建并喂入文档

### 新建知识空间
1. 左侧导航进入"资产 → 知识库"。
2. 点击"新建空间",填写名称。
3. 选择可见性:
   - **私有**:只有你自己能看;
   - **共享**:登录用户都能看,只有你能改;
   - 公开(预留)。

### 导入文档
1. 进入空间 → 上传文件(支持 PDF / Word / Markdown / Excel 等)。
2. 系统自动解析并生成 wiki。大文档会异步处理,稍等片刻即可。
3. 也支持从飞书 wiki 同步(在空间中配置同步来源)。

### 浏览知识结构
空间内有"目录树 / 图谱"视图,可以看到文档之间、概念之间的关联。

## 三、把知识库接到应用

在应用编辑页绑定该知识空间后,Agent 即可检索。详见《应用构建》手册。

## 四、常见问题

- **上传后 Agent 还是查不到?** 文档解析和 wiki 生成是异步的,等任务完成;
  另外确认应用绑定的是这个空间。
- **文档更新了怎么办?** 重新上传同名/新版文档,系统会生成新版本并保留演进历史;
  检索默认取最新有效版本。
- **想删除某份文档?** 在空间内删除对应文档即可,相关 wiki 与关联会一并清理。
