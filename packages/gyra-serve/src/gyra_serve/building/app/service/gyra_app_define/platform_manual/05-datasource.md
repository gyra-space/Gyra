# 数据源(数据库接入)

> 数据源模块用于把各类数据库接入平台,让 Agent 能查询真实业务数据、
> 做数据分析和报表生成。支持 MySQL、Oracle、Doris、PostgreSQL 等 20+ 种数据库。

## 一、接入一个数据库

1. 左侧导航进入"资产 → 数据库"。
2. 点击"新建数据源",选择数据库类型。
3. 填写连接信息(主机、端口、库名、账号密码)。
4. 点击"测试连接",通过后保存。

> 也支持上传 DDL 建表语句文件,让系统离线学习表结构(不连真实库也能让 Agent 理解 schema)。

## 二、让 Agent 用上数据源

- **绑定到应用**:在应用的资源绑定里加入该数据源,Agent 就能执行 SQL 查询。
- **在场景空间里用**:把数据源注册为空间资产,空间 Agent 可直接查询。

## 三、配合 ECP 做语义增强

如果业务字段含义复杂(如"gmv""uv"等业务术语),建议配合"资产 → ECP"维护语义资产:
给指标和字段加上业务含义,Agent 查数据时能理解"销售额"对应哪个字段、怎么算。

## 四、常见问题

- **连接测试失败?** 检查网络可达性、账号权限、以及数据库类型是否选对;
  部分老旧版本(如 Oracle 11g)需要特定驱动配置,联系管理员。
- **Agent 查出来的表结构不对?** 可能是 schema 缓存过期,在数据源详情里点"刷新结构"。
- **担心 Agent 误操作数据?** 默认只读查询;写操作需显式授权并逐次确认,且有审计日志。
