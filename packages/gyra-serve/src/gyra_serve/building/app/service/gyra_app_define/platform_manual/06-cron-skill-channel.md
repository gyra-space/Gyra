# 定时任务、技能与消息渠道

> 本篇覆盖三个提升自动化水平的常用能力:定时任务(Cron)、技能(Skill)、消息渠道(Channel)。

## 一、定时任务(Cron)

让 Agent 在指定时间自动执行任务并投递结果(如每天早上发一份数据简报)。

### 创建定时任务
1. 左侧导航进入"能力 → Cron"。
2. 新建任务,填写:
   - **调度规则**:cron 表达式,如 `0 9 * * 1-5` 表示工作日每天 9 点;
   - **执行内容**:要 Agent 做什么(自然语言描述或指定应用/技能);
   - **投递渠道**(可选):结果发到哪里(见下方"消息渠道")。
3. 保存后可在"任务引擎(Jobs)"查看每次执行的状态与结果。

### 常见问题
- **任务没按时跑?** 检查 cron 表达式和时区设置,以及任务是否被暂停。
- **想看历史执行记录?** 到"能力 → 任务引擎(Jobs)"按任务筛选。

## 二、技能(Skill)

技能是封装好的"标准操作流程(SOP)",让 Agent 遇到对应任务时按既定步骤执行,保证质量稳定。

### 获取与安装技能
1. 进入"能力 → Skill"。
2. 从技能市场浏览并安装,或上传自己的技能包(SKILL.md)。
3. 在应用的资源绑定里挂载该技能,Agent 即可使用。

### 编写自己的技能
技能以 `SKILL.md` 描述:适用场景、输入、标准步骤、注意事项。
写好后发布到技能库,即可被多个应用复用。

## 三、消息渠道(Channel)

把 Agent 能力接入飞书、钉钉等 IM,让同事在群聊里直接 @机器人 提问,
或把定时任务的结果推送到群里。

### 配置渠道
1. 进入"能力 → 渠道"。
2. 新建渠道,选择 IM 类型,填入机器人凭证(App ID / Secret 等)。
3. 把渠道绑定到应用或定时任务。

### 常见问题
- **机器人不回复?** 检查凭证是否过期、事件回调地址是否配置正确。
- **定时任务没推到群里?** 确认任务的投递渠道已绑定且机器人已在目标群。
