# DESIGN.md — 业务场景 Loop 全链路（深色科技风）

## 1. 画布与母版

- 画布 1280×720，页面 padding：上下 20px、左右 64px。
- **A · 标题块**：0–120px（含上 padding 20）。主标题 36px bold，左侧 8px 宽强调色竖条；标题下方 16px 灰色副标题（可选）。
- **B · 内容区**：120–660px（540px 可用）。一切正文/图/卡片。
- **C · 页脚条**：660–720px。左侧 "Gyra · 业务场景 Loop" 14px 灰字 + Gyra logo（L3，32×32），右侧页码 `NN / 12` 14px 灰字。
- 封面/结束页自定义版式，可省略 C 区。

## 2. 颜色系统（≤4 hex 主色板）

| 角色 | hex | 用途 |
|---|---|---|
| 背景主色 | `#0F172A`（深海军蓝） | 全篇页面背景 |
| 主色 | `#3B82F6`（蓝） | 标题竖条、主流程节点、卡片头部 |
| 辅色 | `#22D3EE`（青） | 第二系列、连接线、次级强调 |
| 强调色 | `#F59E0B`（琥珀橙） | 巨型数字、核心焦点、北极星标注（≤10%） |
| 文本主色 | `#F1F5F9`（近白） | 标题与正文（中性色，不计入色板） |
| 文本次色 | `#94A3B8`（灰蓝） | 副标题、脚注、页码 |

- 卡片背景：`rgba(59,130,246,0.10)` 或 `#1E293B`（深一档面板），边框 `rgba(148,163,184,0.25)`。
- 渐变：封面蒙版 `linear-gradient(90deg, rgba(15,23,42,0.95) 0%, rgba(15,23,42,0.55) 55%, rgba(15,23,42,0.25) 100%)`；强调渐变 `linear-gradient(135deg, #3B82F6 0%, #22D3EE 100%)` 用于关键节点/标题装饰线。
- 色彩面积：主色 ≤60%（含背景面板）、辅色 ≤30%、强调色 ≤10%；Hero 页强调色可达 15%。页面 03/07/11 色彩比例与其他页显著不同（强调色更高）。

## 5. 密度与留白

- 常规内容页正文 ≥180 字、留白 ≤35%；卡片填充率 ≥85%，尾部元素 `marginTop: auto` 锚底。
- 视觉锚点：每页 ≥1 个（≥44px 元素或 ≥40% B 区主视觉）；焦点周围 ≥40px 呼吸空间。
