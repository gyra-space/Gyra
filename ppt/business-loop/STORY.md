# STORY.md — 业务场景 Loop 全链路：让数据可信，让 Agent 越用越强

## ① 用户意图对齐

- **目标受众**：客户（企业决策者 / 业务负责人 / 技术负责人），售前交流或产品宣讲场合。听众不是 AI 专家，需要"能听懂"的讲法。
- **核心目标**：讲完后客户相信三件事——① Gyra 的业务 Loop 能保证数据**稳定、准确、可信**；② 数据在场景里**持续循环**而不是一次性用完；③ 每一次使用都让**数据和 Agent 一起成长**，越用越强。记住一句话："业务数据越跑，飞轮越快，空间越用越厚。"
- **PPT 长度**：12 页（Hero 页 3 页：封面 / 全景图 / 结束页，占比 25%）。
- **视觉调性**：深色科技、专业克制、飞轮感、客户友好。
- **内容边界**：必讲——数据稳定准确（语义层+硬门禁）、数据循环（触发→执行→交付）、数据学习（沉淀+漂移检测）、成长（记忆进化+剧本演化）、人机分工。不讲——L1 LLM Loop 工程细节（死循环检测、上下文压缩等）、代码实现、内部路线图。禁碰——编造客户案例与数据。

## ② 页面布局骨架

- **总数 12 页，不分章**（客户宣讲节奏：痛点 → 全景 → 四大能力 → 协同 → 价值）。
- **Hero 页**：01 封面、03 业务 Loop 全景、12 结束页。间隔合规。
- **rhythm 曲线**：01 peak → 02 valley（痛点）→ 03 peak（全景）→ 04 valley → 05 valley → 06 valley → 07 peak（成长飞轮，小高潮）→ 08 valley → 09 transition（三闭环咬合）→ 10 valley → 11 peak（客户价值）→ 12 peak（收尾）。
- **非对称版式预算**：02（左标题+右内容）、04（非对称双栏）、05（上大图+下方卡片→改横向流程+下卡）、06（左大图+右侧文字）、07（非对称双栏）、08（左标题+右内容）、10（左标题+右内容）、11（巨型数字+洞察）→ 8/12 = 67% ≥ 40%。
- **对称版式预算**：01（全屏视觉+大标题）、12（居中金句），共 2 页，达标。
