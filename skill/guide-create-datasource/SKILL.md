# 接入数据源引导

## 适用场景

用户想把自己的数据库接入 Gyra，让 Agent 能查询真实业务数据。
覆盖 MySQL、Oracle、PostgreSQL、Doris 等 20+ 种数据库。

## 引导流程

### 第 1 步：确认数据库类型与连接信息

向用户确认以下信息（若用户已提供则跳过对应项）：
- 数据库类型（MySQL / Oracle / PostgreSQL / Doris / 其他）
- 主机地址与端口
- 数据库名
- 账号与密码（提醒：建议用只读账号，降低误操作风险）

### 第 2 步：在平台创建数据源

引导用户操作：
1. 左侧导航进入「资产 → 数据库」。
2. 点击「新建数据源」，选择对应数据库类型。
3. 填写第 1 步收集的连接信息。
4. 点击「测试连接」。

### 第 3 步：处理连接失败（如有）

若测试连接失败，按以下顺序排查：
1. 网络是否可达（数据库是否对平台服务器开放）。
2. 账号密码是否正确、是否有登录权限。
3. 数据库类型是否选对（部分老旧版本如 Oracle 11g 需特定驱动，引导联系管理员）。

### 第 4 步：让 Agent 用上数据源

连接成功后，告诉用户两种使用方式：
- **绑定到应用**：在应用编辑页 → 资源绑定 → 添加该数据源。
- **在场景空间用**：把数据源注册为空间资产，空间 Agent 即可查询。

### 第 5 步（可选）：语义增强

若业务字段含义复杂（如 gmv、uv 等术语），建议配合「资产 → ECP」维护语义资产，
让 Agent 理解"销售额"对应哪个字段、怎么算。详见 ECP 手册。

## 注意事项

- 全程提醒：默认只读查询，写操作需显式授权并逐次确认，有审计日志。
- 若用户只是想离线学习表结构（不连真实库），告知可上传 DDL 建表语句文件。

## 收尾确认

完成后向用户确认：数据源是否已连接成功、Agent 是否能查到数据。
若仍有问题，引导查看「资产 → 数据库」详情页的连接状态。
