# 搭建知识问答应用引导

## 适用场景

用户想把一批文档（产品手册、规章制度、业务资料等）变成一个可以对话问答的 AI 助手。

## 引导流程（四步）

### 第 1 步：创建知识空间并导入文档

1. 左侧导航进入「资产 → 知识库」→「新建空间」，填写名称。
2. 选择可见性：私有（仅自己）/ 共享（登录用户可读）。
3. 进入空间，上传文档（支持 PDF / Word / Markdown / Excel）。
4. 告知用户：系统会自动解析并生成结构化知识，大文档需稍等片刻（异步处理）。

### 第 2 步：确认文档已就绪

- 在空间内查看文档解析进度，或直接进入下一步（后台会继续处理）。
- 若文档量大，提醒用户稍后再验证问答效果。

### 第 3 步：创建问答应用

1. 进入「能力 → Agent」→「新建应用」，选择"单 Agent"模式。
2. 填写名称（如"产品知识助手"）。
3. 编写角色提示词，例如：
   "你是产品知识助手，基于知识库回答用户问题，先检索再回答，不知道就说不知道。"

### 第 4 步：绑定知识库并发布

1. 在应用编辑页 → 资源绑定 → 添加「知识库」，选择第 1 步建的空间。
2. 绑定后应用自动获得检索能力（search_knowledge / read_knowledge_document）。
3. 点击「发布」。

## 验证效果

引导用户回到对话，问一个文档里有答案的问题，确认：
- 应用能检索到文档内容并给出带依据的回答。
- 若答不上来，检查文档是否已解析完成、应用绑定的是否是正确空间。

## 注意事项

- 文档更新：重新上传新版文档即可，系统会生成新版本，检索默认取最新有效内容。
- 提示词里建议明确"先检索再回答、不编造"，效果更佳。

## 收尾确认

向用户确认：应用是否已发布、问答是否符合预期、是否需要调整提示词。
